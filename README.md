# 滑轨控制

面向林升机电蓝牙步进电机控制板的原生 Android 控制应用，包名为 `com.lingsheng.slidercontrol`。本项目不是控制器厂商的官方应用。

目标硬件是用户提供的淘宝商品：[42/57 步进电机驱动控制器套装（DRV8825）](https://e.tb.cn/h.jovrlhyuN0T5jkg?tk=xSdt66LN51n)。商品短链接和具体批次未在此项目中验证；使用前请核对控制板型号与协议。

## 使用

1. 先在 Android 系统蓝牙设置中与控制板配对，再回到应用选择设备连接。
2. 打开“设置”，填写控制板地址、每毫米步数和留足两端安全余量后的最大可用行程。校准值未知或无效时，运动控制会保持禁用。
3. 主界面速度以毫米/秒显示。按住正向或反向按钮开始连续移动，松开会优先排队停止帧；底部停止按钮始终可见。应用不能确认电机已经停稳。
4. 应用不显示实际位置，因为旧控制板协议没有被确认会回报可解析的位置或动作完成状态。
5. 点主界面的“案例”可离线搜索 `范例` 目录中的 45 份 TXT。详情页保留完整原文；能由单块蓝牙控制板独立运行的程控组可选择方案和启动组、编辑参数、预览蓝牙帧并直接执行。需要双板、外接按键、继电器或未确认指令的内容保留原文说明；随附图片和视频可在对应案例页查看。

手动连续移动没有软件行程限制，设置的最大可用行程只用于校验定距离参数。手动移动时必须全程看护；在确认控制板断连停机和实体限位前，保持可触及的断电开关。

## AB 两点循环

连接控制板并完成校准后，可设置 A 到 B 的距离并选择无限循环或 1–98 次。A 点固定使用控制板位置 `0`；B 点按 `距离 × 步数/毫米` 换算成步数，再用控制板程控支持的 16 位参数精确表示。若当前速度超出程控速度范围，或 B 点步数无法精确表示，应用会拒绝启动。

开始时应用会覆盖控制板的“200+”程控组，写入速度、A/B 点和循环次数，再发送“200+”启动指令。连续模式使用循环值 `99`。底部停止按钮发送 CH 停止指令。控制板不回报实际位置或运行状态，因此 App 不能确认命令是否已执行，也不能显示实测行程。

AB 采用点击写入时主界面的运行速度。卡片会显示下次写入速度，点击后显示本次排队采用的毫米/秒和微秒/步。若要修改保存的 AB 速度，请先停止、调整主界面速度，再重新写入。运行中按加减只发送即时调速命令，不修改 AB 保存的程序。

1.1-speed 修正了即时调速命令与官方 App 不一致的字节排列；同一显示速度下的手动移动可能与旧版不同。178 步/毫米时，5、10、20 mm/s 对应约 1124、562、281 微秒/步。

1.2-examples 增加单板案例的方案/启动组选择，并收录范例随附图片和视频。案例中的速度是程控行自己的“微秒/步”参数；主界面的即时调速不会自动改写已存的案例配方。修改案例速度后需重新写入。

1.3-calibration-layout 将未设置的每毫米步数预填为 198（保留用户已保存的数值）；仍须填写最大可用行程才能启用运动。连接状态提示固定占两行，按住手动正反向按钮时不会因提示字数变化而推动按钮。

开始前请确保控制板的零点对应滑轨 A 端，B 点距离已留出两端余量，并确认“200+”程控组可被覆盖。首次实机使用请设置低速、短行程并全程看护。

## 构建

需要 JDK 17、Android SDK Platform 37.0 和 Build Tools 36.0.0。接受 Android SDK 许可后，运行：

```powershell
.\gradlew.bat :app:assembleDebug
```

输出位于 `app/build/outputs/apk/debug/app-debug.apk`。这是调试签名 APK，可直接安装到允许安装未知来源应用的 Android 手机。

已有工作区工具链可运行 `.\checks\run-speed-checks.ps1` 检查调速协议及 AB 参数传递，不连接电机。它使用 `checks/support` 下的离线蓝牙替身；这些文件不打包进 Android 应用。

## 协议与硬件验证

`docs/protocol-notes.md` 记录了从 3.7 APK、指令表和 AB 范例恢复的 6 字节协议、程控帧和证据边界。实际控制板地址、方向、速度、停止延迟、断连停机、零点和行程边界仍需在控制板和滑轨上验证。首次使用请按以下顺序低速检查：

1. 确认滑轨两端留有足够余量，并确保能立即切断电源。
2. 点动正向，松开后确认电机停止且方向符合预期。
3. 点动反向，再次确认方向和松开后的停止行为。
4. 测试底部停止按钮；若方向、停止或连接行为异常，立即断电，不要继续长行程操作。
5. 确认“200+”程序槽可覆盖、零点在 A 端后，再用低速和短距离试跑 AB 循环，测试停止响应和往返方向。

当前硬件不可用，AB 往返和实体限位行为均未实测。

## 案例 / 配方库

案例列表按运动程控、遥控设置、外设与联动、用户案例分类，也可按名称、用途或原始路径搜索。每条详情展示来源路径和完整 TXT 原文。

只有能按工作簿转换为已知预置组与命令 70 程控行的案例会显示“写入并运行”。详情可选择方案和启动组、修改程控参数、预览全部写入帧和启动帧；开始前会列出要覆盖的组。每组写入后发送 CH 结束设定，再运行所选组。无限循环和端口/外部硬件操作需要分别勾选确认。延时指令按工作簿分为时长与结束后命令；原文数字与注释矛盾时，界面提醒并以数字指令为准。

红外遥控键映射码不是串口帧。双控制板和红外一拖多只展示原文和随附媒体；外接按键、限位和继电器的接线与触发设置保留在原文中。若同一案例另有清楚的单板程控组，App 允许手动启动该组，不会配置外接触发。继电器/端口程控会要求确认外部硬件；程控里直接调用连续正转/反转时也会显示单独确认。被调用的预置组必须包含在本次写入配方中，调用链不能互相成环；无法区分的绿色组启动编号 4 和工作簿未确认的操作码 18 不提供直接启动。应用不能确认蓝牙队列已被控制板执行，也不能确认电机到位。
